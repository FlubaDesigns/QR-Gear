Claude — QRG schema enforcement is still incomplete.

You fixed part of the schema, but the runtime flow still violates the locked QRG system.

FINAL QRG FORMAT:
Base:
QRG-[STNNN]-[C]-[IIIIII]

Full variant/barcode:
QRG-[STNNN]-[C]-[IIIIII]-[SSCC]

Allowed context codes:
I = Internal
M = Member
E = External
O = Owner

No DDD/build number.
No provider IDs.
No fake fallback SKUs.

============================================================
WHAT IS STILL WRONG
============================================================

1. admin-build-sessions.ts still generates old QRG codes:
QRG-${blankCode}-${source}-${buildStr}

That is wrong because:
- source/context is in wrong conceptual flow
- buildStr/build number was removed
- it does not allocate 6-digit instanceNumber

2. admin_catalog_instances does not enforce QRG identity.

When an admin/internal instance is created, it must store:

qrgBlankId
qrgContext
instanceNumber
qrgBaseCode
variantCode, if selected
qrgFullCode, if selected
sourceMasterId

Example:
qrgBlankId: "11101"
qrgContext: "I"
instanceNumber: "000001"
qrgBaseCode: "QRG-11101-I-000001"
variantCode: "0501"
qrgFullCode: "QRG-11101-I-000001-0501"

3. member_library_instances does not enforce QRG identity.

Member instances must use:

qrgContext: "M"

Example:
QRG-11101-M-000001

4. useCreatePacket.ts still has forbidden client-side QRG allocation:

Remove:
QRG_BLUEPRINT_BLANK_CODES
/qrg/allocate
blueprint-to-QRG mapping

Packet creation must use the selected master product and instance identity. It must not invent QRG IDs.

5. surface-generator.ts still references old:
QRG-{MASTER6}-{INST4}

Remove it.

Surfaces must use existing instance QRG codes only.

6. marketplace/orchestration still have fake/fallback SKU generation.

Remove fallback patterns like:
QRG-${surfaceId...}
QRG-{type}-{seq}

If no valid qrgBaseCode exists, fail instead of inventing one.

REQUIRED FIX
============================================================

Create one shared server-side allocation helper, for example:

functions/src/services/qrg-instance-allocator.ts

It should export:

allocateQrgInstance({
  qrgBlankId,
  context,
  sizeCode?,
  colorCode?
})

Rules:
- validate qrgBlankId with shared/qrgCodes.ts
- validate context is I, M, E, or O
- allocate next 6-digit instanceNumber
- build qrgBaseCode:
  QRG-[STNNN]-[C]-[IIIIII]
- if size/color exists, build:
  variantCode = SSCC
  qrgFullCode = QRG-[STNNN]-[C]-[IIIIII]-[SSCC]

Return:
{
  qrgBlankId,
  qrgContext,
  instanceNumber,
  qrgBaseCode,
  variantCode,
  qrgFullCode
}
